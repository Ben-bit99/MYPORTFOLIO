# Abdul Wahib Rao: Portfolio

An immersive, HUD-style WebGL portfolio for a Game & XR developer. It has scroll-driven 3D scenes, a text-scramble interface, synthesised ambient sound, a video-ready game showcase, and a grounded RAG chatbot.

**Stack:** Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · React Three Fiber / three.js · Framer Motion · Lenis · Vercel AI SDK (Gemini or OpenAI) · Zod

```bash
npm install && npm run dev
```

| Doc | What |

## Where things live

```
src/data/portfolio.ts        ← SINGLE SOURCE OF TRUTH (UI + chatbot)
src/data/knowledge/*.md      ← extra notes for the chatbot
src/data/rag-index.json      ← generated by `npm run rag:index`
src/components/three/        ← procedural scenes (City, Works, Timeline, Vault)
src/components/Sections.tsx  ← Hero / About / Works / Timeline / Vault / Contact
src/components/video/        ← ProjectVideoPlayer, hover preview, slot placeholder
src/components/chat/         ← AI chat panel
src/components/Memories.tsx  ← guestbook section, form, ghost memories
src/components/HoloCertificate.tsx ← interactive certificate hologram
src/lib/memories/            ← guestbook storage (Redis or file)
src/lib/sound.ts             ← generative score + UI sounds
src/app/api/chat/route.ts    ← retrieval + grounded streaming answers
src/lib/rag/                 ← chunking, BM25, hybrid retriever, provider config
scripts/build-rag-index.ts   ← index builder
```
